[[context:mkf-format.md]]

请使用C++和Qt，根据mkf格式的描述文档，构建一个GUI工具，用于可视化mkf文件的结构。要求如下：

1. 可视化界面分两部分，左边为一个树状视图，可以点击展开或收起，右边显示左侧选定的对象的属性
    - 属性包括该对象在文件中的起始位置、文件中的大小、解压缩后大小
2. 树状视图顶级为mkf文件，展开后为文件中的所有资源，资源编号为0到(资源个数-1)
3. 资源可以展开，如果是未压缩资源，直接展开为"Decompressed Data"，压缩后的资源展开为"Compressed Data"，再进一步展开为"Decompressed Data"
4. 如果解压后的数据为SPR/SMP资源，可以进一步展开，列出资源中的所有图像数据
    - 每个图像数据，右侧显示的对象属性加上图像大小和位置属性，并显示图像是8比特还是16比特
5. 对于可展开的对象，请提示可以展开
    - 对于 **Decompressed Data**，可以通过检测前4字节判断是否为SPR/SMP资源，如果是，请提示可以展开，否则不可展开
6. 提供二进制查看器，用于查看每个对象的数据，二进制查看器的UI类似于常见的二进制编辑器，即左边显示地址和每个字节的16进制表示，右边显示可打印字符
7. 提供图像预览器，用于预览图像数据
    - 所有每像素16比特的图像数据都是RGB565数据
    - 所有每像素8比特的图像数据格式位置，可暂时指定为任意一种8比特像素的数据
    - 提供图像缩放功能
    - 预览时请忽略图像的 x,y 位置属性
8. 允许用户提取视图中的任意对象到文件
9. 实现查找文件中SPR/SMP资源的功能：
    - 如果未选定视图中的任意对象，找到第一个SPR/SMP资源
    - 如果已选定视图中的对象，找下一个SPR/SMP资源
    - 提示：可以在调用 ``mkf_decompress`` 解压时，设置 ``bufsz`` 参数为4,从而只解压压缩数据的前4字节，加快查找速度
10. 加载文件的速度需要尽可能地快，即打开文件时不要解压全部数据

数据解压功能由C语言函数 ``mkf_decompress`` 实现，该函数已经由第三方库实现，函数原型为：

``c
// 输入 src: 经过压缩的数据
// 输入 bufsz: dst指向的缓冲区大小
// 输出 dst: 解压后的数据
// 支持部分解压，即该函数只会写入bufsz字节至dst，即使解压未结束
void mkf_decompress(void *dst, const void *src, size_t bufsz)
``
